# CS Labs

This solution contains five independent C# lab projects.

## Structure

Each lab lives under `labs/` and can be built or run independently:

```text
labs/
├── Lab01-Basics/
├── Lab02/
├── Lab03/
├── Lab04/
└── Lab05/
```

Shared code, if needed by more than one lab, belongs in a separate project under
`shared/` rather than in another lab project.
